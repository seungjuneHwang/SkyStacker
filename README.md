# 🏗️ SKY STACKER (스카이 스태커)

> **"하늘을 찌르는 나만의 타워, 완벽한 타이밍을 노려라!"**  
> `SKY STACKER`는 웹 브라우저에서 마우스 클릭이나 터치 한 번으로 즐길 수 있는 미니멀 3D 아케이드 퍼즐 게임 및 공식 소개 랜딩 페이지 프로젝트입니다.

## ✨ 핵심 기능 (Key Features)

- **🕹️ 직관적인 원버튼 조작:** 마우스 클릭, 터치, 스페이스바만으로 언제 어디서나 플레이 가능
- **✂️ 실시간 절단 물리 연출:** 타이밍이 어긋나면 블록이 잘려 나가며 타워가 점차 좁아지는 긴장감 제공
- **🌈 네온 레인보우 시각 효과:** 타워가 높아질수록 HSL 색상 축이 변화하는 감성적인 무지개빛 3D 아이소메트릭 렌더링
- **🔥 콤보 & 보상 시스템:** 3회 연속 'PERFECT' 달성 시 줄어든 블록 크기가 회복되는 역전 메커니즘
- **🏆 실시간 글로벌 리더보드 UI:** 명예의 전당 및 층수 달성 뱃지(Cloud Architect ~ Orbital Stack Master) 시스템

---

## 🛠️ 기술 스택 (Tech Stack)

### Frontend & Web Publishing
- **HTML5 & CSS3**
- **Tailwind CSS (v3)** - 유틸리티 퍼스트 기반의 반응형 UI 및 네온 글로우 스타일링
- **Vanilla JavaScript (ES6+)** - Canvas 2D/3D 프로젝션 렌더링 엔진 및 Web Audio API 효과음 합성
